# Raeesa Samaai · Heritage Editorial portfolio concept

A **one-page interactive React + Tailwind CSS portfolio mockup** with a modern heritage/editorial scrapbook aesthetic, built for design review.

## Design direction
- Signature palette: vintage green `#507252`, deep burgundy `#671C19`, ivory `#F6F1E9`, parchment `#E7D8C5`, muted clay `#B77862`.
- Original SR monogram traced from the supplied transparent logo into `public/sr-mark.svg`.
- Intentionally subtle paper grain, realistic stationery layering, botanical illustration, paper clips, vintage postage and wax-seal motifs.
- Clear visual hierarchy: scrapbook elements complement rather than obscure a modern website.

## Sections
1. Hero
2. Selected Work (category filter + project detail dialogs)
3. Skills & Technologies
4. Journey — work and learning experience
5. About
6. Testimonials (explicit placeholders, not fabricated endorsements)
7. Contact

## Run locally
```bash
npm install
npm run dev
```
Open the local address shown by Vite. Use `npm run build` for a production bundle.

## Notes for review
- The project names, professional timeline, and professional links come from the prior portfolio in this repository.
- Project thumbnails are **stylised conceptual previews**, not photographs or exact screenshots of the real projects.
- Testimonials and email / résumé delivery are **not populated** until confirmed.
- This mockup lives in its own repository and does not replace the existing `My-Digital-Portfolio` site.
- Social/profile links: [GitHub](https://github.com/raeesasamaai) and [LinkedIn](https://www.linkedin.com/in/raeesa-samaai-831081312/).

## Tech
Vite, React, Tailwind CSS v4, custom CSS and lucide-react. No external image assets are required; Google Fonts use a network connection when available.
